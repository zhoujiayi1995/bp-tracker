# 欧姆龙 HEM-1026 屏幕识别

从中国版 HEM-1026 的照片读取高压、低压、脉搏和「血压偏高」指示格。拍摄时保留蓝色开始键和三组读数。工具可处理横拍、倒拍和局部反光。一条命令处理一张图片，向标准输出写入 JSON 后退出。

## 使用

在本目录下安装依赖并运行。已在 Python 3.10 上验证。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m bp_ocr ../ocr-test-photos/*_221_59.jpg
```

加上 `--debug-dir DIR` 可查看转正图、屏幕边框、拉正屏幕、照明估计、归一化图、二值图、未知像素掩膜和数字框。每张照片可指定独立目录。

| 字段 | 含义 |
| --- | --- |
| `systolic`、`diastolic` | 高压、低压，单位 mmHg |
| `pulse` | 脉搏，单位 次/分 |
| `high_indicator` | 屏幕指示格亮起为 `true`，熄灭为 `false`，无法辨认为 `null` |
| `confidence` | 各数字字段的笔画证据评分，范围 0–1，未经概率校准 |

三组读数均通过校验时退出码为 0。有多种可能段码或读数越界时，对应字段为 `null`，退出码为 1。三组数字未同时出现或屏幕定位失败时，整组读数为 `null`。输入或参数错误的退出码为 2，诊断写入标准错误。

## 单核运行

`BP_OCR_MAX_EDGE` 默认 1280，图片解码后先按比例缩小。仅在 960 × 480 的拉正屏幕上估计反光。启动前设置 `BP_OCR_THREADS` 可更改线程数，默认值 1 同时用于 OpenCV、OpenBLAS 和 OpenMP。

## 验收

```sh
.venv/bin/python -m unittest discover -s tests -v
```

实拍测试从仓库里的 `ocr-test-photos/` 逐张读图、核对三个字段并打印耗时。笔画阈值在这批照片上核对过，26 张的结果代表对这些样本的回归覆盖。另有合成七段字、同图四向旋转、遮挡、量程和测量中画面的测试。

`testdata/expected.json` 以照片屏显为准。转正后核对出两条原计划标注差异，三元组依次为高压、低压、脉搏。
